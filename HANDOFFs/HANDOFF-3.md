ИЗВЕСТНЫЕ ДОЛГИ И КОСЯКИ

1. dice.resolve_flee — в докстринге "3-4 — ушёл, но враг может
   ударить (hit_roll >= 4)". По уточнению пользователя
   (11.10.2026) правильно "hit_roll < 4 — удар". То есть
   попал, если бросок МЕНЬШЕ 4. Проверить, поправлено ли.
   Если нет — тесты dice могут быть кривые.

2. combat._enemy_spell — при блоке против каста шамана
   бросок атаки врага НЕ тратится, а MP тратится. Это
   уникальный случай: блок "съедает" каст. Обсудить,
   правильно ли это. В тестах не покрыто.

3. combat._burt_flee — при побеге 6 counter уходит
   первому живому врагу. При нескольких врагах — не
   проверено тестами. Если правило "counter только
   первому" — ок. Если "counter каждому" — баг.

4. combat.resolve_round — при action="flee" и неудаче
   (outcome="ongoing") фаза врагов пропускается, потому
   что враг уже ударил внутри _burt_flee. Но шаман при
