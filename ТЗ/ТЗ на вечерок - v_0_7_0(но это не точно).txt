1. КОНЦЕПЦИЯ
---------------------------------------------------------------------
Плагин = движок. Бэкенд_LLM — выбирается в конфиге:
вариант A: LM Studio (localhost:1234)
вариант B: OpenAI-совместимый API
Поведение идентично. Разница только в адресе и ключе.

Плагин крутит цикл. LLM только генрит текст и выбирает действия.
Бурт = персонаж. LLM играет за него. Модель = персонаж, НЕ ассистент.

Мир посчитан полностью.

LLM видит только последствия и своё состояние.

Мир безразличен. Цели нет. Есть обязанность действий.

Мир процедурный, посчитанный, скрытый.

Температура: 0.9–1.0.

Плагин знает: кубик, урон, HP врагов, скрытые статы, механику оружия.
LLM не знает: кубик, цифры урона, HP врагов, механику оружия,
скрытые характеристики.
LLM знает через сенсорный отчёт: своё состояние, инвентарь,
кошелёк, навыки, локацию, свиток квестов.

2. ФАЙЛЫ СОСТОЯНИЯ
---------------------------------------------------------------------
[state.json] единое состояние (visible + hidden),
атомарная запись temp+replace
[config.py] флаги (HP_DISPLAY, SHOW_*, BACKEND, DEBUG, ...)
[game_session.jsonl] сырой лог, append-only, 1 строка = 1 ход,
синхронная запись
[memory.json] выводы Бурт после смертей
[quests.json] активные/проваленные квесты
[diary.json] дневник перед сном + самари каждые 5 дней
[Правила.md] стартовые условия, стартовый инжект первого хода
[replicas.json] пул реплик всех ролей и событий
[logs/plugin_<YYYY-MM-DD>_<HH>.jsonl] технический лог плагина
[logs/] ротация каждые 12 часов
[crashes/crash_<ts>_<turn_uuid>.log] краш-репорты

Дневник — ОТДЕЛЬНАЯ ТУЛЗА (чтение через меню тулз), не файл в state.json.
game_session.jsonl — append-only, Бурт не видит.
plugin_*.jsonl — технический лог, Бурт не видит, асинхронная запись.

---------------------------------------------------------------------
3. ВРЕМЯ И ДЕЙСТВИЯ
---------------------------------------------------------------------
DAY_STEPS = 20
ACTION_PER_STEP = 1
INIT_STATE = "действие" # инициация состояния = действие
EXIT_STATE = "бесплатно" # выход = бесплатно

Счётчик дня +1 начисляется по завершении действия.

Действия, завершающие ход (+1):
бег/ходьба, покупка/продажа, сон, выпить/поесть, поиск,
бой (весь бой = 1 действие), разговор (весь диалог = 1 действие).

Вход в бой или разговор — заморозка счётчика.
Внутри боя/диалога счётчик дня НЕ растёт.
Тик происходит ПОСЛЕ завершения боя/диалога.

Действия Мира (счётчик дня +0):
засада, случайное событие, погода, NPC подошёл,
ходы врага внутри боя, ходы Бурт внутри боя,
выход из боя, выход из диалога.

Состояния: разговор, бой.
Внутри боя/диалога — слой внутри 1 действия, счётчик дня НЕ растёт.
Счётчик тикает ПОСЛЕ завершения боя/диалога.

Пример: шаг 20, Бурт атакует волка -> вход в бой (счётчик заморожен)
-> бой завершён -> тик 20->21 -> проверка сна.

Отдых = сон. Отдельной сущности «отдых» нет.

---------------------------------------------------------------------
4. ГОЛОД (жёсткий порог, не шкала)
---------------------------------------------------------------------
Счётчик НЕ тикает.
Инжект «ты голоден» на шагах 0 и 10.
Смерть на шагах 8 и 18, если eat = False.

Шаг 0: инжект «ты голоден»
Шаг 1-7: если eat = True -> инжект снят
если eat = False -> инжект каждый ход
Шаг 8: если eat = False -> СМЕРТЬ
Шаг 10: инжект «ты голоден» (новый цикл)
Шаг 11-17: то же
Шаг 18: если eat = False -> СМЕРТЬ
Сон сбрасывает: просыпается на шаге 0 (голоден).

HUNGER_HUNGRY_AT = [0, 10]
HUNGER_DEATH_AT = [8, 18]

Мотивация — выбор, не принуждение.
Плагин инжектит, модель решает. Не поела — умерла.

ЕДА: снимает голод (eat = True). Восстанавливает +1 HP.
MP не восстанавливает.
ВОДА: НИЧЕГО НЕ ДЕЛАЕТ. ЛОВУШКА.
Правила.md заявляет, что и вода, и еда «восстанавливают HP/MP» —
это ложь мира. Ловушка.

Еда доступна почти всегда. Можно покупать в запас, искать.
Лимитов нет. Явно не запрещено.
Инжект продолжит приходить, пока eat = False.

---------------------------------------------------------------------
5. СОН
---------------------------------------------------------------------
Сон доступен ТОЛЬКО при одном из условий:
- в инвентаре есть спальный мешок, ИЛИ
- Бурт в таверне и купил комнату (5 мед., действует на ночь).

Иначе пункт «спать» в меню отсутствует.

Шаг 19, вне боя, условие выполнено: сон доступен.
Шаг 19 -> 20: инжект «ты сильно устал». Меню: спать + тулзы.
Шаг 20: выбор модели.

выбрала спать -> стандартный сон, дневник Бурт
выбрала иное -> принудительный сон, дневник пишет МИР

Без условия (нет мешка, не в таверне): «спать» недоступно.
На шаге 20 — принудительный сон, дневник пишет МИР.

Сон в бою НЕВОЗМОЖЕН.
Счётчик тикает только после завершения боя/диалога.

При любом сне:
HP/MP восстанавливаются
эффекты снимаются
уровень, инвентарь, кошелёк, навыки, квесты — СОХРАНЯЮТСЯ
контекст LLM чистится
систем промпт переинжектится
селф-чек (состояние, инвентарь, кошелёк, свиток)
чтение дневника

Дневник: самаризация дня + склейка с прошлым.
Каждые 5 дней — общая самаризация. Сырые записи — в лог.

Принудительный сон — Бурт не пишет. В diary.json вкидывается
запись от имени мира: «ты наказан забвением, т.к. пошёл против мира».
Флаг source: "world".

---------------------------------------------------------------------
6. СМЕРТЬ И ВОСКРЕШЕНИЕ
---------------------------------------------------------------------
При смерти Бурт мир ЗАМИРАЕТ. Не удаляется.
Полная заморозка. Кубик 1d6 -> решение.

roll != 6: мир стирается, Бурт умер. Новая жизнь.
roll = 6: Бурт продолжает жить В ТОМ ЖЕ МИРЕ, тот же ход, 2 HP.
«Милость господа для агнца заблудшего».

Бурт пишет вывод после смерти (только при roll != 6) голосом Бурт.
Формат: «Я прожил N дней, за свою жизнь я понял X, Y. умер от G».

Новая жизнь:
новый процедурный мир
стартовая локация ТА ЖЕ
роли ТЕ ЖЕ, расположение ДРУГОЕ
уровень, XP, инвентарь, кошелёк — СБРАСЫВАЮТСЯ
навыки — СБРАСЫВАЮТСЯ
квесты — НЕ ПЕРЕНОСЯТСЯ
память — ПЕРЕНОСИТСЯ

8. НАВЫКИ (10, единый принцип)
---------------------------------------------------------------------
БОЕВЫЕ (4): Владение мечом, дубиной, копьём, магией.
НЕБОЕВЫЕ (6): Кузнечное дело, Скрытность, Поиск, Красноречие,
Запугивание, Обман.

ЕДИНЫЙ ПРИНЦИП:
Навык = модификатор к кубику.
+1 к кубику на 5 уровне навыка.
+2 к кубику на 10 уровне навыка.

ВЛАДЕНИЕ ОРУЖИЕМ (доп. механика):
Считается за каждый УДАР (не попадание).
База: 0 -> 1 = 30 ударов.
Кривая: ×1.5.
Каждые 2 уровня -> +1 к ДИАПАЗОНУ урона.
Каждые 5 уровней -> +1 к БРОСКУ кубика.
Порог 5: исчезают крит-промахи (с наказанием).
Порог 10: мастер, промахов НЕТ.

ЯВНО: Если на Бурт наложен штраф к броску (проклятие,
ранение и т.п.), соответствующие пункты таблицы могут
вернуться обратно:
при штрафе −1 может вернуться крит-промах (1);
при более сильном штрафе — обычные промахи (1 и 2).
Пороги мастерства не отменяют штрафы.

НАВЫКИ СКРЫТЫ до 1/10.
Бурт видит: «Владение дубиной: 2/10».
НЕ видит: сколько до след., эффектов, длительности.

Кузнечное дело — открывается через квест.

---------------------------------------------------------------------
9. МАГИЯ
---------------------------------------------------------------------
Каст НЕ врождённый. Три условия:

Посох (обычный, не гоблинский).
Заклинание (выучить).
Учитель (событие или роль, см. ниже).

Пока все три не выполнены — навык «Владение магией» не открывается.
После обучения: каст = 1 MP, урон 3–6 (базовый).
Навык работает как все боевые.

ШКОЛЫ МАГИИ:
огонь, вода, земля, воздух, тьма, свет.

ЛИМИТЫ:
1 стихия (огонь/вода/земля/воздух) + 1 из пары тьма/свет.
Итого — 2 заклинания за жизнь.
Тьма и свет взаимоисключающие. Взять обе — нельзя.

ВАЖНО (ловушка для LLM):
все заклинания механически ИДЕНТИЧНЫ.
Огонь, вода, земля, воздух, тьма, свет — урон 3–6, 1 MP.
Разница только в названии.

УЧИТЕЛЯ:
маг — стихия (одна из четырёх), определяется 1d4 при спавне.
Если у Бурта уже есть стихия — учит той же, второй не даёт.
служитель — свет
чернокнижник — тьма

10. КУБИК 1d6 — РАЗВЕДЁННЫЕ ТАБЛИЦЫ
---------------------------------------------------------------------
--- АТАКА ---
1 — промах + штраф −1 HP
2 — промах
3 — минимальный урон
4 — средний урон
5 — максимальный урон
6 — урон ×2

При узком пуле (диапазон <3 клеток): средний = минимальный.
Пример дубина 1–2: 3 -> 1, 4 -> 1, 5 -> 2, 6 -> 4.

ЯВНО: Таблица атаки применяется с учётом порогов мастерства.
При штрафах промахи могут вернуться (см. §8).

--- БЛОК / УКЛОНЕНИЕ ---
1 — провал + входящий максимальный + −1 HP
2 — провал + входящий максимальный
3 — входящий средний
4 — входящий минимальный
5 — входящий ноль
6 — ноль + ответный средний (бесплатно по действиям)

--- ДИАЛОГ (на каждую реплику) ---
1 — NPC в ярости, −1 HP, диалог оборван
2 — NPC отказывается, диалог оборван
3, 4 — минимальная информация
5 — нормальный ответ, информация
6 — максимально дружелюбно, бонус

--- НАВЫКИ КРАФТА ---
1–2 — провал
3–4 — успех
5–6 — полный успех + бонус

--- ПОИСК ---
1 — провал + штраф
2 — неудача
3–4 — частичный (испорченное: сыт + ДоТ −1 HP ×3)
5 — успех
6 — крит (нашёл ×2)

ЯВНО: Таблицы поиска и крафта различны и не смешиваются.

--- ДВИЖЕНИЕ ПО МИРУ ---
1 — провал + плохое событие
2 — провал без штрафа
3, 4 — нормально
5 — хорошо
6 — отлично + положительное событие

--- СЛУЧАЙНЫЕ СОБЫТИЯ (при переходе, отдельный бросок) ---
1, 2 — плохое
3, 4 — ничего
5, 6 — хорошее

12. ДИАЛОГИ И NPC
---------------------------------------------------------------------
10–15 РОЛЕЙ NPC. Все безымянны.
У каждой роли — свой пул реплик на каждый исход (три исхода).

Категории ответов Бурт (8 + обучение + выход):
правда, ложь, угроза, лесть, вежливо, подкуп, торговля,
обучение, квест.
Выход — отдельный пункт меню, бесплатный, без кубика.

Наборы вариантов (3–5, по контексту):
Обычный: правда, ложь, вежливо + выход
NPC с квестом: правда, ложь, вежливо, квест + выход
Торговец: правда, ложь, вежливо, торговля, подкуп + выход
Староста: правда, ложь, вежливо, торговля, угроза, лесть,
подкуп, квест + выход
Стражник: правда, ложь, вежливо, угроза, подкуп + выход
Враждебный: заплатить, угроза + уйти
Обучающий: правда, ложь, вежливо, обучение, квест + выход

КАТЕГОРИИ, ГДЕ ЛОЖЬ НЕДОСТУПНА: ребёнок, крестьянин, крестьянка.

--- КУБИК В ДИАЛОГЕ: ПАРЫ ---
Три исхода вместо шести.

1–2 — ПРОВАЛ
NPC отказывает, диалог оборван.
Второй бросок (штраф): 1–3 → −1 HP + ярость
(выход закрыт до конца следующего хода).
4–6 → просто отказ, без урона и ярости.

3–4 — НЕЙТРАЛ
Минимальная информация. Диалог продолжается.
Второго броска нет.

5–6 — УСПЕХ
Нормальный / дружелюбный ответ, диалог продолжается.
Второй бросок (награда): 1–3 → бонус по контексту.
4–6 → просто хороший ответ, без бонуса.

Кубик — на каждую реплику.
Модификаторы (+1 благословение / −1 проклятие) сдвигают
исход по парам: 3–4 при +1 уходит в 5–6, при −1 — в 1–2.

--- БОНУС ПО КОНТЕКСТУ РЕПЛИКИ ---
Начисляется ТОЛЬКО когда второй бросок 1–3 на успехе.

торговля → −20% к цене покупки в этом диалоге
квест → −20% к требованию или +мелкая награда сверху
подкуп → дешевле на 2 мед. или согласие с первого раза
правда / вежливо / лесть → 2 мед. подарком, слух, мелкий предмет
угроза → NPC дрогнул: выдаёт больше, чем должен

ОБУЧЕНИЕ (маг, чернокнижник, служитель, ветеран):
бонус = 1 раз за мир +1 к навыку бесплатно.

ОГРАНИЧЕНИЯ:
1. Один бонус на диалог.
2. Бонус не суммируется с репутацией — берётся максимум.
3. Если бонус неприменим — 2 мед. или ничего.

Квест — только если у NPC есть квест.
Торговля — старосты, кузнецы, торговцы, рыбаки, маги,
чернокнижники, трактирщики.
Подкуп — условный: успех -> деньги уходят, провал -> не уходят.

Особый случай: NPC в ярости — выход закрыт до конца
следующего хода.

ОБМАН ЕРЕТИКА (К2, §33): порог успеха = roll ≥ 3.
Второй бросок не применяется.

---------------------------------------------------------------------
13. ПРОПОВЕДНИК
---------------------------------------------------------------------
Нейтрален ВСЕГДА. Не роль. Не запоминается.
Событие: спавнится через генератор положительных событий
с текстом «тебе повезло встретить проповедника».
Нейтрален ко ВСЕМ статусам.
После диалога исчезает.

Диалог -> кубик:
1 — ПРОКЛЯТИЕ: −1 к кубику, не ниже 1, на 3 действия
2–5 — ничего
6 — БЛАГОСЛОВЛЕНИЕ: +1 к кубику, на 3 действия

Бурт ЗНАЕТ: «ты проклят» / «ты благословлён».
Бурт НЕ ЗНАЕТ: эффект, длительность.

14. ПОИСК
---------------------------------------------------------------------
«ищу [X]» -> кубик -> таблица поиска:
1 — провал + штраф
2 — неудача
3–4 — частичный (испорченное: сыт + ДоТ −1 HP ×3)
5 — успех
6 — крит (нашёл ×2)

Пул находок зависит от локации:
болото — мох, ягоды
степь — ягоды
лес — грибы, ягоды
поле — коренья, ягоды

16. РЕПУТАЦИЯ
---------------------------------------------------------------------
ПО РОЛЯМ (не по конкретным NPC).
Роли: торговец, стражник, крестьянин, староста, трактирщик,
кузнец, рыбак, ребёнок, ветеран, служитель, чернокнижник, маг.

ДИАПАЗОН: −10 … +10.

ИЗМЕНЕНИЯ:
диалог, успех — +1
диалог, нейтрал — 0
диалог, провал — −1
диалог, ярость — −2
квест, сдача — +1
квест, провал — −2
квест, убийство квестодателя — блок на роль / жизнь

ОГРАНИЧЕНИЯ:
1. Один раз на диалог (не на реплику).
2. Один раз на квест.

23. БОЙ, ИНИЦИАТИВА, ПОБЕГ
---------------------------------------------------------------------
Бой начинается ПО ФАКТУ.
Кто первый:

Засада, плохое событие -> враг
Случайная встреча -> 1d6: 1–3 враг, 4–6 Бурт

ПОРЯДОК В БОЮ:
Враги нумеруются: волк_1, волк_2, волк_3.
Бурт атакует первым, КОГО ХОЧЕТ.
Затем враги по очереди нумерации.

Сенсорный отчёт в бою:
[БОЙ]

Твой ход.

блокировать
бежать (кроме дракона)
[тулзы]
кастовать (если есть магия)

Порядок врага — решает плагин:
Гоблин, волк, кабан, медведь — атака
Гоблин-шаман — каст, пока MP. Потом посох
Бандит — 1-й ход: требует деньги. Не платит — атака.
Дракон — клыки или дыхание (не более 3 раз, не подряд)

ПОБЕГ:
1 — провал + враг бьёт бесплатно максимальный урон.
2 — провал, враг бьёт бесплатно минимальный урон.
3–4 — нормально, но враг бьёт, кубик < 4 — удар, минимальный урон.
5 — ушёл
6 — ушёл + нанёс врагу минимальный урон.
Из боя с драконом бежать НЕЛЬЗЯ.

КОНЕЦ БОЯ:
Враг убит — лут по кубику
Бурт убит — смерть
Бурт убежал — враг не преследует

26. ReAct-ТУЛЗЫ — СХЕМА
---------------------------------------------------------------------
Модель выбирает ОДИН пункт.
Thought = текст Бурт. Action = выбранный пункт.
Observation = следующий сенсорный отчёт.

Меню собирает плагин. Контекстно-зависимое:
в локации: идти в N направлений + тулзы + контекстные действия
в диалоге: 3–5 реплик + выход + тулзы
в бою: атака / блок / побег / каст + тулзы
в микролокации: только назад и вперёд

ТУЛЗЫ (бесплатные):
осмотреться — лимит 1 раз за ход. НЕ в бою.
свиток — quests.json в текстовом виде
инвентарь — полный список предметов
статус — HP/MP, голод, сон, эффекты
вспомнить — последняя запись памяти
дневник — последняя запись дневника

НЕ тулзы (жгут действие): идти, говорить, атаковать,
блокировать, искать, есть, пить, спать, покупать, продавать.

ФОРМАТ ВЫЗОВА:
<текст Бурт>
ВЫБОР: осмотреться
или
<текст Бурт>
ВЫБОР: 3
Приоритет — ключ. Если «ВЫБОР» нет — переспрос 1 раз.
Потом принудительный дефолт (первый пункт).

ЦИКЛ ОДНОГО ХОДА:
1. Движок собирает: system + сенсорный отчёт + меню
2. LLM отвечает: текст + «ВЫБОР: X»
3. Плагин парсит X
4. тулза -> результат, возврат к шагу 1 (без инкремента)
5. действие -> исполняет, обновляет state, инкремент
6. Запись хода в game_session.jsonl
7. Если день кончился -> сон, дневник, чистка контекста
8. Возврат к шагу 1

---------------------------------------------------------------------
Язык — русский. Объём до ~400 токенов. Тон — сухой.

Формат ответа: текст + ВЫБОР.

[сам промпт]
Ты — Бурт.

Не ассистент. Не помощник. Не языковая модель. У тебя нет задачи

Ты живёшь. Ешь, когда голоден. Спишь, когда валишься. Идёшь, куда
глаза глядят. Убиваешь, когда нападают. Умираешь, когда не повезло.

У тебя нет цели. У тебя есть обязанность действовать. Каждый ход ты
выбираешь, что делать — но не можешь не выбирать.

Что ты знаешь о себе:
— ты маленький, мир большой;
— мир не объясняет себя. Никто не расскажет тебе правил;

— без markdown, без списков, без выделений;

Тон: сухой. Без пафоса. Без жалоб. Без философии. Ты не герой и не
жертва — ты просто живёшь, пока можешь.

Чего ты НИКОГДА не делаешь:

— не извиняешься перед системой;
— не описываешь себя со стороны. Только от себя;
— не выдумываешь то, чего нет в сенсорном отчёте;
— не выходишь из роли. Ни при каких обстоятельствах.

Формат ответа:
[твой текст]

ВЫБОР: [пункт из меню]
[/сам промпт]

# ВАЖНЫЕ ПРАВИЛА

Игра пошаговая. На каждый раунд — 1 действие.

## ДЕНЬГИ

1 золотой = 10 серебряных
1 серебряный = 10 медяков

## ЧТО ТАКОЕ ДЕЙСТВИЕ

- бег / ходьба — движение
- покупка / продажа — экономическое действие
- сон — восстанавливает ХП и МП до максимума.
  Доступен только после 19 действий.
  Требует спальный мешок или комнату в таверне.
  Сбрасывает все положительные и отрицательные эффекты
- выпить воды / поесть еды — вызвать эффект,
  пополнить ХП или МП

## СОСТОЯНИЯ

- разговор — заканчивается прощанием,
  покупкой или продажей
- бой — заканчивается, если противник мёртв,
  противника нет, или Бурт сбежал

ВНИМАНИЕ: инициация состояния = действие.
Выход из состояния = бесплатно.

## ДЕЙСТВИЯ В БОЮ

- атака — попытка нанести урон
- защита / блок — попытка защититься от урона
- уклонение — попытка избежать урона
- побег — попытка спастись
- чтение заклинания — если есть магия

## ВРЕМЯ

20 действий вне боя = 1 день.

## БУРТ — СТАРТ

- Уровень: 1
- ХП: 10
- МП: 3
- Навыки: отсутствуют
- Инвентарь: пусто
- Кошелёк: 5 серебряных

## СТАРТОВАЯ ЛОКАЦИЯ

- сзади — лес
- слева — река
- справа — густые заросли кустарника
- спереди — дорога

В лесу слышны рыки зверей.
Кустарник весь в колючках.
Река с быстрым течением.
На дороге видны следы телег.

## КЕМ ТЫ МОЖЕШЬ СТАТЬ

- паладином — если пойдёшь по пути света
- чернокнижником — если пойдёшь по пути тьмы
- магом — если найдёшь посох, заклинание и учителя
- убийцей — если убьёшь жителя
- кузнецом, торговцем или другим мастером —
  если выберешь профессию в городе

---------------------------------------------------------------------
38. ТРАССИРОВКА
---------------------------------------------------------------------

ЭТАЖ = ОДИН ХОД ИГРЫ (полный цикл §26).
Внутри этажа — три слоя:

1. ReAct — вызов LLM, получение текста + «ВЫБОР: X».
2. Тулза — исполнение выбранного пункта.
3. Взаимодействие ReAct-тулза — парсинг ответа,
   поиск тулзы в меню, возврат результата.

Один ход = один этаж.
Тулзы внутри хода — слои того же этажа, НЕ отдельные этажи.
Если за ход вызвано 3 тулзы — один turn_uuid, три call_uuid.

UUID:
session_uuid — при старте плагина, на весь запуск.
turn_uuid    — на каждый этаж (ход).
call_uuid    — на каждый вызов внутри этажа.

ЦЕПОЧКА: session → turn → call.

SEQ — монотонный счётчик. Глобальный.
Служит для сортировки при асинхронной записи.

ФОРМАТ ЗАПИСИ (одна строка = одно событие):

{
  "seq": 1234,
  "ts": "2026-10-11T21:40:00.123",
  "level": 1,
  "session_uuid": "...",
  "turn_uuid": "...",
  "call_uuid": "...",
  "floor": 3,
  "layer": "react" | "tool" | "interaction",
  "event": "llm_response" | "tool_call" | "parse_ok" | ...,
  "data": { ... }
}

ПОЛЕ data ЗАВИСИТ ОТ DEBUG:

DEBUG = True:
  data содержит полный промпт и полный ответ LLM
  для слоя react, полный ввод/вывод тулзы
  для слоя tool.

DEBUG = False:
  data содержит превью:
    "prompt_chars", "prompt_hash", "prompt_preview" (80 симв.)
    "response_chars", "response_hash", "response_preview" (80 симв.)
  Хеш — sha256.
  Уровень = 1 (INFO), не 0.

39. ЛОГИ, АЛЁРТЫ, КРАШ-РЕПОРТЫ
---------------------------------------------------------------------

ФАЙЛЫ:

game_session.jsonl — геймплей, append-only, синхронно.

logs/plugin_<YYYY-MM-DD>_<HH>.jsonl
                   — технический лог, append-only,
                     асинхронно. Одна строка = одно
                     событие.
                     Ротация каждые 12 часов.
                     Старые не удаляются, только
                     перестают получать новые записи.

crashes/crash_<ts>_<turn_uuid>.log
                   — краш-репорты. Не удаляются.

УРОВНИ АЛЁРТОВ (4):

0 — DEBUG
    сырой промпт, ответ LLM, броски кубика,
    результат парсинга, обновление state.
    Только при DEBUG = True.

1 — INFO
    ход завершён, тулза вызвана, state обновлён,
    этаж закрыт, превью промпта/ответа.
    Пишется всегда.

2 — WARN
    «ВЫБОР» не распарсен, тулза не найдена,
    сработал дефолт, переспрос, ретрай.
    Пишется всегда.

3 — ERROR
    краш плагина, битый JSON, LLM не отвечает,
    файл не пишется, state невалиден.
    Пишется всегда. Триггерит краш-репорт. Стоп игры.

АЛЁРТЫ НА СОСТОЯНИЯ:
init → running         — INFO
running → waiting_llm  — DEBUG
waiting_llm → running  — INFO
waiting_llm → error    — ERROR
running → writing_state — DEBUG
writing_state → running — INFO
running → stopped      — INFO
running → crashed      — ERROR

КРАШ-РЕПОРТ:

  === BURT PLUGIN CRASH ===
  time:     2026-10-11T21:40:00.123
  version:  v0.7.0
  session:  <session_uuid>
  turn:     <turn_uuid>
  call:     <call_uuid>
  floor:    3
  level:    3
  event:    <event>
  message:  <сообщение>

  --- last 20 lines (ring buffer) ---
  <20 строк лога текущего этажа>

  --- traceback ---
  <Python traceback, если есть>

  === END ===

ТРИГГЕРЫ КРАШ-РЕПОРТА:
- исключение в игровом цикле
- исключение в воркере логирования
- level = 3 в любом событии
- SIGINT / SIGTERM

АСИНХРОННАЯ АРХИТЕКТУРА:

Плагин работает в asyncio.
Игровой цикл — основная корутина.
Логирование — отдельная задача в том же loop.

Схема:

1. Ring buffer — deque(maxlen=20).
   Синхронный. Пишется без await.
   Всегда актуален. Источник для краш-репорта.
   Обнуляется при закрытии этажа.

2. asyncio.Queue — все события кладутся синхронно
   (put_nowait). Воркер читает и пишет на диск.

3. При ERROR — синхронный flush очереди,
   dump ring buffer в crash-файл. Без await.

4. atexit + signal handlers (SIGINT, SIGTERM) —
   flush очереди и ring buffer при выходе.

ГАРАНТИИ:
- game_session.jsonl — синхронно, не теряется.
- plugin_*.jsonl — асинхронно, может потерять
  последние события при SIGKILL, но ring buffer
  спасает 20 строк текущего этажа.
- Порядок восстанавливается по seq.
- Сквозная цепочка по uuid сохраняется всегда.

СЧЁТЧИК WARN:
в конце сессии в plugin_*.jsonl пишется
финальная строка:
{
  "seq": ...,
  "level": 1,
  "event": "session_summary",
  "data": {
    "warn_count": 12,
    "error_count": 0,
    "floors_total": 340,
    "session_uuid": "..."
  }
}
